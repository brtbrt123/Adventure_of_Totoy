# 0005: 384x216 view and the SpriteCook fantasy UI

Owner approved the 384x216 review mockups and explicitly chose "Switch the game to 384x216" on 2026-10-28. Integration completed 2026-10-29.

The base view is now 384x216, still with 16x16 tiles, nearest-neighbour art, `canvas_items` stretch and integer scaling. The default window is 1152x648 (3x); 1536x864 gives 4x. Characters and map art keep their native game-pixel dimensions, so the camera shows 20% more world on each axis. This supersedes the resolution and default window in decision 0004; its window-resolution text approach remains.

The owner approved the SpriteCook bronze frames with teal gems and asked to reuse existing katana, Sprint and other icons. Installed parts are in `art/ui_kit`; their sizes and 9-slice borders are in `kit.json`. `presentation/common/ui_kit.gd` draws the parts. The approved source, palette conversion, credits and licence notes remain in `art/reference/ui_kit_spritecook_v1/README.md`. No additional SpriteCook credits were needed for integration.

Words use Cinzel. Original bitmap numeral/key glyphs in `art/ui_kit/pixel_keys.fnt` make 5, Z and C distinguishable; `make_pixel_font.py` reproduces the font atlas. Frames, font atlas and icons use Totoy 36 and hard alpha. UI art excludes reserved gold/red.

The menu has Status, Aspects, Items and Quests tabs, keyboard/gamepad navigation and mouse hitboxes. Stats, equip requests and objective text still read the core snapshots. Existing 320x180 intro art is centred at native size inside the view. Weapon cut-ins keep their original composition centred in the new screen, with the dim veil covering the whole view.

Known interface limitation: `ExploreSnapshot` exposes no Edge amount or Aspect cooldown/run timers. The road HUD shows an unavailable Edge track instead of inventing a value; arena meters/timers use their existing HUD snapshot. Claude should extend the exploration contract if those live values are wanted. No core edits are part of this change.

Live captures and validation notes: `presentation/review/ui_kit_live/`.
